# Scroll Curator for Twitter/X


**Save Twitter stuff you actually care about.**

Twitter's built-in bookmarks are a black hole—you save things and never see them again. This is a simple browser extension that captures tweets (with images!) and lets you export them as Markdown files for your notes.

## What it does
- Floating counter badge on Twitter
- Auto-saves viral tweets (5000+ likes) to "Most Liked" folder
- Manual bookmark button (🔖) on every tweet for "Read Later"
- Click any saved tweet to see full image + text
- Export daily digest as Markdown (works great with Obsidian/Notion)

## Install
1. Download this folder
2. Go to `chrome://extensions/` → Enable "Developer mode"
3. Click "Load unpacked" → Select this folder
4. Done. Go to Twitter, you'll see a small badge top-right.

## That's it.
No accounts, no cloud, no data collection. Everything stays on your computer. If Twitter changes their code and it breaks, that's life.

**Note:** This tool accesses Twitter content on your behalf. Use it responsibly and don't spam anyone.
